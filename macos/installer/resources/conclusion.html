Installation Complete

Setup now runs in the background — you can close this installer.

Setup is complete once the Unify menu-bar icon (tray app) appears near the clock. It turns green when services are running.

What happens next:

  • Dependencies and services finish installing automatically (this can take a few minutes on first install).
  • If you entered your API key, services start and Screen Sharing is enabled for you.
  • If you skipped the key, open the menu-bar icon and choose Settings… to enter it — setup completes after that (you'll be asked to approve Screen Sharing once).

To watch progress you can run:
tail -f /opt/unify-desktop-assistant/logs/postinstall-deferred.log
