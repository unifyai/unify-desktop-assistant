Welcome to Unify Desktop Assistant

This installer will set up Unify Desktop Assistant on your Mac so it can be controlled remotely through your Unify account.

During installation it will:

  • Install the assistant and its dependencies to /opt/unify-desktop-assistant.
  • Ask you for your Unify API Key to finish setup (you can skip this and enter it later).
  • Request your permission to enable Screen Sharing, so the desktop can be viewed remotely.
  • Add a menu-bar app for starting/stopping services and managing settings.

Don't have your API key handy? Just click Skip when prompted — you can add it any time from the menu-bar icon under Settings….
